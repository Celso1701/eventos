# RIZZIERI ONE — V:1.12.0

PWA "Life, Business & Projects" — central única para projetos, eventos, financeiro e vida pessoal em
quatro workspaces (Negócios, Eventos, Pessoal, Ideias).

## Estrutura
```
index.html / css/app.css / js/app.js / manifest.json / sw.js / assets/icons/ / SECURITY.md
```

## Publicar no GitHub Pages
```
git init && git add . && git commit -m "RIZZIERI ONE V:1.12.0"
git remote add origin <seu-repositorio> && git push -u origin main
```
Settings → Pages → branch `main`, pasta raiz. **Substitua a pasta inteira a cada atualização.**

## Novidades desta versão
Removidas as 2 menções ao corsyncimoveis que ainda apareciam em texto visível (tela Sobre e seção
Plano). Contratante do evento agora busca/cadastra cliente. Máscara de dinheiro nos campos Orçamento
previsto, Preço de referência e Valor contratado.

## Dados
localStorage do navegador. Baixe backup em Ajustes → Ajuda/Backup antes de trocar de aparelho.
